Stream Commands

Get your chat commands here by clicking on them to copy to paste in the Twitch, YouTube, or Kick chat!
  • LIVE

General Commands

  • !420 Basic command example
  • !accountage Displays your account age
  • !HG How Much of Hungry Gremlin are you!
  • !adhd Shows ADHD info
  • !birthday Displays birthday details
  • !setbirthday (Use MM/DD) Set your birthday
  • !resetbirthday (Mods only) Reset birthday info (mods only)
  • !lurk Enter lurk mode
  • !unlurk Exit lurk mode
  • !summon Summon command
  • !troll Troll a viewer
  • !nospoiler Avoid spoilers
  • !throne My Throne Wishlist
  • !gribbish Words are Hard

Fun and Interaction

  • !battle Choose a target for battle. For example: Fallen chooses the troll to fall into Despair.
  • !bonk Bonk someone playfully
  • $clip Clip a moment from the stream
  • !chaos Unleash chaos in chat
  • !dork Send a playful insult
  • !dungeon Enter the dungeon
  • !fart Trigger a funny fart sound
  • !hugs (@ someone) Give someone a virtual hug
  • !dadjokes Tell a dad joke
  • !donno Express uncertainty
  • !umbrella Bring an umbrella
  • $add qotd Add a new quote
  • $delete qotd Remove a quote
  • $qotd Randomly selecta quote
  • $edit qotd Edit an existing quote
  • !tarot Draw a tarot card

Game and Score Tracking

  • !deaths Display death count
  • !death- Subtract a death
  • !death+ Add a death
  • !resedeaths Reset death count
  • !wins+ Increase win count
  • !wins- Decrease win count
  • !resetwins Reset wins

Moderation and Utility

  • !cuss- Lower cuss count
  • !cuss+ Increase cuss count
  • !resetcuss Reset cuss count
  • !resetyawn Reset yawn counter
  • !subtier Display subscriber tier
  • raid (no "!") Initiate a raid
  • !hidehr Hide Heart Rate

Music and Entertainment

  • !play Play the current track
  • !pause Pause the music
  • !skip Skip to the next song

Special Features

  • !gametags Show game tags
  • !elgatoOn Activate Elgato lighting
  • !elgatoOff Deactivate Elgato lighting
  • !pr Show PR information
  • !hogwarts Enter Hogwarts mode
  • !dnd (Choose a class) Start Dungeons and Dragons
  • !quiz !startquiz Begin a quiz session
  • !answerquiz !answer Submit your quiz answer
  • !stopquiz End the quiz session
  • !leaderboard Show quiz leaderboard

Moderator Commands

  • /ban Ban a user
  • /timeout Timeout a user
  • /clear Clear the chat
  • /slowmode Toggle slow mode
  • /raid Initiate a raid
  • !so Shout out a user
  • !grounded Grounding the user for 69 seconds

VIP Commands

  • !highlight Highlight a moment
  • !roast Send a playful roast
  • !cheer Cheer for the streamer

Subscriber Commands

  • !subemote Use subscriber emotes
  • !loyalty Check loyalty points
  • !emotes List available emotes

Follower Commands

  • !followage Display follow duration
  • !social Show social links
  • !latest Show latest stream info
