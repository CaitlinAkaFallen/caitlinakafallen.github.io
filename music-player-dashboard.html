Auto-post to a Discord channel every time the track changes, using a Discord webhook. This runs from the dashboard only — keep this tab open (or your OBS/streaming PC) for posts to fire.
When ON, every new "now playing" track detected in the Queue tab gets posted automatically.
In Discord: Channel Settings → Integrations → Webhooks → New Webhook → Copy Webhook URL.
Placeholders: {title}, {artist}, {album}. This becomes the embed title text.

Next Song Alert

Post a separate "coming up next" message a few minutes before the current track ends, using the next track in your Spotify queue. Uses the same webhook, bot name, avatar, and embed color set above.
Fires once per track, based on the current track's remaining play time — not a fixed timer. Needs a track waiting in your Spotify queue.
Left border color of the embed card
Posts once remaining time on the current track drops to or below this many minutes.
Placeholders: {title}, {artist}, {album}, {remaining} (e.g. "4:12 left").

Pause Song Alert

Post a separate "pause" message when the current track is paused.
Fires once per track, when the current track is paused.
Left border color of the embed card
Placeholders: {title}, {artist}, {album}.

Resume Play Alert

Post a separate "resumed" message when playback resumes after being paused.
Fires once each time playback goes from paused to playing.
Left border color of the embed card
Placeholders: {title}, {artist}, {album}.
